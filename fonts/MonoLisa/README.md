# MonoLisa

Coloque aqui os arquivos `.ttf`/`.otf` da sua licença da MonoLisa
(baixados de <https://www.monolisa.dev> com a sua conta).

**Atenção:** a MonoLisa é uma fonte comercial — os arquivos NÃO devem ser
commitados neste repositório público (violaria a licença). Por isso o
`.gitignore` ignora tudo nesta pasta exceto este README.

Para instalar no macOS depois de colocar os arquivos aqui:

```fish
cp ~/dev/dotfiles/fonts/MonoLisa/*.{ttf,otf} ~/Library/Fonts/ 2>/dev/null
```
